# Contributing

Thanks for your interest in contributing to this AAPL expiration tracker!

## How to contribute

1. Fork or clone the repository.
2. Create a new branch for your change (e.g. `your-name/topic`).
3. Commit your changes with a clear message.
4. Open a pull request against `main`.
5. Wait for review before merging.

## Reporting issues

- Only file issues for things specific to this repository (repo setup, file content, missing data).
- Don't open issues for general market data questions.

## Data notes

- All market figures must come from live data (Yahoo Finance option chains).
- If a number looks odd, report exactly what the source returned rather than guessing.
